# 🤖 UTS AI Chatbot

Welcome to the UTS AI Chatbot – a conversational assistant built to answer any questions related to the University of Technology Sarawak (UTS). This project was developed as part of an Object-Oriented Programming (OOP) assignment.

🌟 **Project Purpose**

This chatbot was created to:

-   Provide quick answers about UTS (courses, fees, scholarships, campus facilities, etc.)
-   Explore the integration of AI with a modern, serverless web deployment.
-   Demonstrate core web development principles in a real-world application.

🚀 **Live Demo**

👉 **[Try the chatbot here](https://ai-chatbot-5dy.pages.dev/)**

> Note: The chatbot is deployed on a serverless platform and should be instantly available.

🧠 **Features**

-   Interactive and responsive chatbot interface.
-   AI-powered responses for UTS-related queries.
-   Deployed globally on **Cloudflare Pages** for fast access.
-   Serverless backend architecture using **Cloudflare Functions**.

🛠 **Tech Stack**

-   **Frontend**: HTML, CSS, JavaScript
-   **Backend**: JavaScript (via Cloudflare Functions)
-   **AI Logic**: Google Gemini API Integration
-   **Deployment**: Cloudflare Pages

📚 **For UTS Students**

This chatbot is useful for:

-   New students looking for information about UTS.
-   Those exploring AI chatbot development with modern web technologies.
-   Students interested in practical serverless and full-stack projects.

🎓 **About**

This project was developed for an Object-Oriented Programming course assignment at the University of Technology Sarawak (UTS).
