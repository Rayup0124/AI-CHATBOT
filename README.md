🤖 UTS AI Chatbot

Welcome to the UTS AI Chatbot – a conversational assistant built to answer any questions related to the University of Technology Sarawak (UTS). This project was developed as part of an Object-Oriented Programming (OOP) assignment.

🌟 Project Purpose

This chatbot was created to:

- Provide quick answers about UTS (courses, schedules, campus facilities, etc.)
- Explore the integration of AI with web deployment
- Demonstrate OOP principles in a real-world application

🚀 Live Demo

👉 [Try the chatbot here](https://botbuilders-chatbot.onrender.com)

> Note: The server may take a few seconds to start if it's inactive.

🧠 Features

- Interactive chatbot interface
- AI-powered responses for UTS-related queries
- Deployed on [Render.com](https://render.com)
- Object-oriented design architecture

🛠 Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask or FastAPI)
- AI Logic: Custom logic or OpenAI integration
- Deployment: Render.com

📚 For UTS Students

This chatbot is useful for:

- New students looking for UTS information
- Those exploring AI chatbot development
- Students applying OOP in practical projects
